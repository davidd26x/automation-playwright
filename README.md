# 🎭 Playwright Automation Suite

Este repositorio contiene un framework de automatización de pruebas **End-to-End (E2E)** y **API** desarrollado con **Playwright** y **TypeScript**. El proyecto está estructurado siguiendo buenas prácticas de QA para garantizar pruebas mantenibles, escalables y eficientes.

---

## 🚀 Tecnologías Utilizadas

* **[Playwright](https://playwright.dev/):** Framework de automatización.
* **[TypeScript](https://www.typescriptlang.org/):** Lenguaje de programación con tipado estático.
* **[Node.js](https://nodejs.org/):** Entorno de ejecución de JavaScript.

---
